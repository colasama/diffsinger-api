      自填乐谱

      干声合成

      小节线 | 可省略，只有使用时才校验每小节拍数。支持连续填写多组谱词。

      谱子格式与可选参数
      写法含义
      1 2 3 4 5 6 7音阶，每音默认一拍，以空格分隔。
      0 / 0:2休止一拍 / 两拍，不占歌词；纯休止行的歌词填 -。
      1' / 1,高 / 低一个八度，使用英文符号。
      #4 / b7升 / 降半音。
      5:2 / 3:0.5 / 3:1.5两拍 / 半拍 / 一拍半，一拍始终为四分音符。
      (2:0.5 3:0.5)一字多音，括号中不能有休止符。
      |（可省略）使用时才校验小节拍数，歌词可对应分节。
      行(xing)指定中文读音，不带声调。
      1=C4 BPM=120 4/4可选首行：调号、速度、拍号；这里是默认值。
      LANG=zh / ja / en语言参数，如 LANG=ja；默认中文，日文按音拍、英文按词典音节。

      空行、一般标点忽略；换行不增加停顿。最长 30 分钟，16384 字符；不受 32 秒选段限制。
